# 数据说明

本仓库**不托管原始数据集**，原因有两个：文件较大（原始 CSV 约 25 MB），且数据集版权归原发布方所有。

## 如何获取

1. 访问**和鲸社区**（[heywhale.com](https://www.heywhale.com/)），搜索「拉勾招聘」数据集；
2. 下载 CSV 文件（本项目的原始文件名为 `拉勾招聘.csv`）；
3. 放到本目录下，重命名为 `lagou_jobs_raw.csv`；
4. 执行 `python src/01_data_cleaning.py`。

> 如果你的文件名不同，改一下 `01_data_cleaning.py` 顶部的 `RAW_PATH` 变量即可。

## ⚠️ 使用这份数据前必须知道的两件事

### 1. 它是「按类别封顶采样」的

70 个岗位类别中，有 23 个（33%）记录数 ≥ 400，且集中在 440–450 一线；而现实中 Java 的岗位量是 Perl 的几十倍，在这份数据里两者却几乎一样多。

**后果**：任何「某类岗位占市场百分之几」的结论都不成立。本项目的所有占比结论一律表述为**「样本内占比」**，不做市场需求规模排名。

**好处**：它保证了小众方向（如大数据，582 条）有足够样本量做内部比较。

### 2. 存在大量重复采集

原始数据中同一 `positionId` 有 3,568 个重复组，共 6,580 行冗余记录（占 31%）。

已验证：跨城市重复组为 **0**、组内薪资 **100% 相同** → 确认为同一岗位的多次抓取，非真实招聘需求。清洗时保留 `createTime` 最新的一条。
